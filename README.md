# Vanishing_knowledge_index
The repsository features files that are related to STEM hackathon
Search algorithm
    Designed an algorithm to enable users search through names of interested
    topics or categories. Also, implemented a naïve bayes algorithm to help users
    find out the probable categories even if the exact wording does not match.
Retrieval of content 
    The data is retrieved from a well documented csv file. Through pandas, the
    file is read, converted into a dataframe and properly classified for frontend
    display.
Fallback logic are ensured at each step to prevent breaking of the pipeline at any stage.
